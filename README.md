# Maquette web – Magazine numérique

Maquette d'un site web éditorial consacré aux enjeux du numérique dans notre société. Le projet prend la forme d'un magazine en ligne moderne, mettant en avant des articles autour de la technologie, de ses usages et de son impact sur notre quotidien.

### Fonctionnalités
- Design moderne et épuré.
- Mise en page responsive, adaptée aux ordinateurs, tablettes et smartphones.
- Typographie et éléments visuels pensés pour améliorer la lisibilité.
- Section Hero mettant en avant l'identité du magazine.
- Organisation du contenu sous forme de rubriques et d'articles.

### Technologies utilisées
- HTML5
- CSS3

### Objectif
Créer une maquette web soignée et accessible, en explorant les possibilités de HTML et CSS pour concevoir une expérience éditoriale agréable et adaptée à tous les écrans.

*Projet de maquette front-end — aucun framework JavaScript utilisé.*
